# Brewly Landing Page

Brewly adalah website landing page bertema coffee shop yang dibuat sebagai tugas slicing website menggunakan HTML, CSS, dan JavaScript tanpa framework.

## Fitur

- Responsive (Mobile & Desktop)
- Sticky Navbar
- Hamburger Menu
- FAQ Accordion
- Smooth Scroll
